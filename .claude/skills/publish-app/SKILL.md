Run verify-app. Confirm whether app may be public, whether source may be public, hosting limits, data privacy and target. For static projects deploy only public/ or build output. Use relative URLs for project paths. Check HTTPS, service worker, manifest and install icons. Never send private data or secrets to hosting. Provide deployment steps or perform only authorized actions with available tools. Verify actual live URL before reporting success.
