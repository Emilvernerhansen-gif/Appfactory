---
name: upgrade-stack
description: Evaluate and integrate trusted open-source tools or skills without additional paid APIs.
---
Read docs/TOOLS.md. Match a tool to a concrete need; do not install overlapping frameworks by default. Inspect upstream source, license, exact install instructions and environment compatibility. Prefer pinned releases and project-local installation; record version and source. Review scripts before execution. Never enable billing, add secrets, or transmit user data to a third party without approval. Verify the skill is discoverable or dependency actually works; report blocked prerequisites instead of claiming success.
