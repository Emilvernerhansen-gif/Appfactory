---
name: upgrade-stack
description: Evaluate and integrate trusted open-source tools or skills without additional paid APIs.
---
Read docs/TOOLS.md. Match a tool to a concrete need; do not install overlapping frameworks by default. Inspect upstream source, license, exact install instructions and environment compatibility. Prefer pinned releases and project-local installation; record version and source. Review scripts before execution. Before installing any skill, plugin or agent pack, run `npm run scan-skill -- <dir|git URL>` (NVIDIA SkillSpector, static) and judge every finding it shows (only files an agent executes or obeys; docs/data hits are hidden as noise, `--all` shows them); report real risks; never decide on its unfiltered verdict alone, and never skip the scan. Prefer releases at least 2 weeks old. Never enable billing, add secrets, or transmit user data to a third party without approval. Verify the skill is discoverable or dependency actually works; report blocked prerequisites instead of claiming success.
